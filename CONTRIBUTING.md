# Contributing

We welcome contributions to expand this compliance library.

## How to Contribute

1. **Open an issue** — describe the policy, rule, or framework addition
2. **Fork the repo** — make changes on a feature branch
3. **Submit a pull request** — include the framework control reference

## What We're Looking For

- Additional policy definitions for existing frameworks
- New framework support (SOC 2, ISO 27001, CMMC)
- Sentinel analytics rule improvements
- Remediation automation scripts
- Control mapping corrections

## Guidelines

- Policy JSON must follow Azure Policy schema
- Include the compliance control reference in the description field
- Test policies in audit mode before submitting as deny
- All contributions must be compatible with the Apache 2.0 license

## Questions?

Open an issue or reach out at [proximaintel.com/contact](https://proximaintel.com/contact).
